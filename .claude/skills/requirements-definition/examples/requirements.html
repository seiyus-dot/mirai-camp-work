要件定義書：タスク管理アプリ（task-manager）

プロジェクト概要

やることを忘れずに管理し、終わったかどうかをひと目で確認できるWebアプリを作る。

想定利用者

やることを忘れずに管理したい個人。

解決する課題

やることを頭の中やメモでバラバラに管理していると、忘れたり、終わったかどうか分からなくなったりする。

解決方法

ログインした本人だけが見られるタスク一覧に、やることを追加・完了・削除できるようにする。データは保存されるので、ページを閉じても消えない。

タスクごとにメモや期限を残せるようにし、終わったタスクは別のページでまとめて見られるようにする。

必須機能

Day1 の必須機能（講座の前提）
  1. ログイン
  2. ログアウト
  3. タスクの追加
  4. タスクの一覧表示
  5. タスクの完了
  6. タスクの削除
追加する機能
  1. タスクの編集（内容・メモ・期限を変える）
  2. 完了済みタスクの一覧表示
  3. 表示名の変更

今回は作らないもの

  • 会員登録・パスワード再発行
  • 複数人で一つのリストを共有すること
  • 通知・リマインダー
  • カテゴリー分け・検索

データアーキテクチャ

erDiagram
    USERS ||--o{ TASKS : "持っている"

    USERS {
        uuid id PK "利用者のID"
        text email "メールアドレス"
        text display_name "表示名"
    }

    TASKS {
        uuid id PK "タスクのID"
        uuid user_id FK "だれのタスクか（利用者のID）"
        text title "タスクの内容"
        text memo "メモ"
        date due_date "期限"
        boolean is_done "完了かどうか"
        timestamptz created_at "作った日時"
    }

users（利用者）テーブル

カラム名型必須キー説明
iduuid○主キー利用者のID
emailtext○メールアドレス
display_nametext表示名（設定ページで変更する）

tasks（タスク）テーブル

カラム名型必須キー説明
iduuid○主キータスクのID
user_iduuid○外部キー → users.idだれのタスクか
titletext○タスクの内容
memotextメモ（空でもよい）
due_datedate期限（空でもよい）
is_doneboolean○完了かどうか（最初は false＝未完了）
created_attimestamptz○作った日時
主キー（PK）
そのデータを1つに決めるための番号
外部キー（FK）
ほかのテーブルとつなぐための番号
型
uuid＝重ならないID、text＝文字、date＝日付、boolean＝はい／いいえ、timestamptz＝日時
  • USERS（利用者） と TASKS（タスク） の2種類の情報を保存する
  • 利用者1人に対して、タスクは0個以上ある（図の ||--o{ は「1人に対して複数」という意味）
  • タスクの user_id で、だれのタスクかをつなげる
  • ログイン中の利用者は、自分のタスクだけを見たり操作したりできる
  • 細かな見た目や SQL（データベースへの命令文）は、この段階では決めない

扱う情報

情報項目
利用者ID、メールアドレス、表示名
タスクID、内容、メモ、期限、完了かどうか、user_id、作った日時

完了条件

Day1 の必須機能
  • 正しいメールアドレスとパスワードでログインすると、自分のタスク一覧が表示される
  • タスクを入力して追加すると、一覧に表示される
  • 完了にすると、タスク一覧から消え、完了済みタスクページに表示される
  • 削除すると、一覧から消える
  • ページを再読み込みしても、タスクが消えていない
  • ログアウトするとログインページに戻り、ほかのページは見られなくなる
追加する機能
  • トップページ（/）を開くと、ログイン状態に合わせてログインページかタスク一覧ページに移動する
  • タスク一覧でタスクを選ぶと詳細ページが開き、内容・メモ・期限を変えて保存すると、一覧にも反映される
  • 完了済みタスクページには、完了したタスクだけが表示される
  • 設定ページで表示名を変えると、再読み込みしても変えた名前のまま残っている
  • ログインしていない状態で /tasks などを開くと、ログインページに移動する

  • 完了済みのタスクを「未完了に戻す」ことができるようにするか
  • 表示名をどこに表示するか（ヘッダーなど）
  • 期限が過ぎたタスクを目立たせるか
